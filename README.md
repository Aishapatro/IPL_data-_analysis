# IPL Data Analysis

This project performs data analysis on Indian Premier League (IPL) cricket data to uncover insights about teams, players, and match performance. Using Python and data analysis libraries, the project explores trends such as top run scorers, best bowlers, winning patterns, team performance across seasons, and venue statistics.

## Features

* Data cleaning and preprocessing of IPL datasets
* Exploratory Data Analysis (EDA) using Pandas and NumPy
* Data visualization using Matplotlib and Seaborn
* Analysis of team performance and win percentages
* Player statistics such as top batsmen and bowlers
* Match insights including toss decisions and venue impact

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook / VS Code

## Goal

The main goal of this project is to understand cricket match trends and extract meaningful insights from IPL data through data analysis and visualization.

## Dataset

The dataset contains information about IPL matches, players, teams, runs, wickets, venues, and seasons.
